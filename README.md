# 🚦 El Semáforo de la Rutina Diaria

**El Semáforo de la Rutina Diaria** es una aplicación web interactiva orientada al autoconocimiento y la evaluación del bienestar integral diario. Diseñada con un enfoque humanista de Counseling, la herramienta invita a realizar una pausa consciente para revisar 7 áreas fundamentales de tu día a día.

## 🌟 Características Principales

1. **Evaluación en 7 Áreas del Bienestar**  
   Revisión guiada de Emociones, Actividad Física, Descanso, Trabajo, Estudio (incluyendo la opción "No estudio"), Esparcimiento y Alimentación.

2. **Semáforo Dinámico Inteligente**  
   Algoritmo de estado que pondera prioridades vitales (priorizando alertas en descanso, alimentación y emociones) para definir el color general del día.

3. **Reflexiones y Orientación Nutricional**  
   Sugerencias personalizadas según el estado reportado, un consejo destacado del día y propuestas de recetas fáciles y prácticas para desayuno, almuerzo, merienda y cena.  Se le agregó un botón para visualizar u ocultar 9 recetas prácticas y otro para imprimir las sugerencias del día en las 7 áreas, incluidas las recetas.

4. **Historial Local y Exportación a CSV**  
   Registro automático guardado en el navegador mediante `localStorage` y descarga optimizada del historial completo en formato `.csv`.

## 📥 Cómo Descargar, Clonar y Probar Localmente

### Opción 1: Descargar como ZIP

1. Hacé clic en el botón verde **"Code"** arriba a la derecha en este repositorio de GitHub.
2. Seleccioná **"Download ZIP"**.
3. Descomprimí el archivo en una carpeta de tu computadora.
4. Abrí el archivo `index.html` con doble clic (o con cualquier navegador: Chrome, Edge, Firefox o Safari).

¡Listo! La app funciona de inmediato, sin necesidad de instalar servidores ni dependencias.

### Opción 2: Clonar con Git

1. Abrí tu terminal o consola.
2. Ejecutá el siguiente comando:

```bash
git clone https://github.com/NoeliaOrsini/semaforo-rutina.git
```

3. Entrá a la carpeta del proyecto:

```bash
cd semaforo-rutina
```

4. Abrí `index.html` en tu navegador.
